01 / 安装并启动雷电

  1. 从雷电模拟器官方网站下载 Windows 安装程序，完成安装。
  2. 记下实际安装目录，例如 D:\leidian\LDPlayer9；不同版本或自定义安装位置可能不同。
  3. 启动模拟器，等安卓桌面完全进入。第一次建议只运行一个实例，便于定位问题。
  4. 电脑提示虚拟化未开启时，按电脑厂商及雷电官方说明设置 VT / SVM。软件界面、功能和最新版本兼容性以实际安装环境为准。

本路线不需要 Android Studio，也不需要单独安装 Node.js、npm、开发源码或 ARM 转译包。不要把当前模拟器已经支持的 APK 兼容性等同于任意其他 APK 都可运行。

多实例管理参考雷电官方多开器说明。不要把模拟器里显示的设备名称当成程序的实例编号。

02 / 安装正确的 APK

本版配套文件名为 app-taketwo2.0.3-stepfix-v2-signed.apk。TTRS 桌面版本 2.0.1 与 APK 文件名中的 2.0.3 是不同的版本标识。

  1. 可以在对应 GitHub Release 的附件中单独下载 APK；也可以使用本包的 软件/resources/apk 目录中的同名文件。
  2. 把 APK 拖进已启动的雷电窗口，或使用雷电侧边栏“安装 APK”选择这个文件。
  3. 等待安装完成，在雷电内打开目标应用，自行登录并授予正常使用需要的权限。
  4. 不要误用原版 APK、旧的 v1 补丁或把文件改名后当成 v2。

配套 v2 APK 的 SHA-256：2dc2f8a3744e3eeed01e445061ffb149aa50bcfff18be8e04d9e1b206f34b5e4。

如果提示签名冲突，先处理需保留的数据，再决定是否手动卸载模拟器里的原应用。卸载会清除该应用的本地数据。第三方 APK 的使用和再分发条件独立适用，见同目录“分发说明.txt”。

03 / 配置 TTRS

  1. 完整解压程序包，打开 软件/TTRS.exe。保留旁边所有 DLL、resources、locales 和许可证文件。
  2. 在程序左侧的 选择模拟器 中选择 雷电。首次默认可能选中 AVD，需要手动切换。
  3. 在 雷电安装目录 填写实际目录（例如 D:\leidian\LDPlayer9），也可直接填写 ldconsole.exe 或 dnconsole.exe 的完整路径。
  4. 核对 实例索引，默认是 0；多个实例时应与雷电多开器对应编号一致。点击 启动雷电 并等待安卓桌面，保持对应实例运行。
  5. 点击 预先定位，在目标应用里检查是否到了路线起点。定位不对时先修正目录、实例和权限，不要立即开始。
2.0.1 保留 AVD / 雷电两种模式，但“步数兼容”区域的检查与安装入口仅在 AVD 模式下显示。使用雷电时，按上一节通过雷电安装 APK，不要套用测试版的 AVD 检查流程。

04 / 地图与路线

  1. 需要在线地图时，在高德开放平台创建 Web 端（JS API） Key，并取得同一条 Key 对应的安全密钥。
  2. 在 TTRS 的“地图与高级设置”完整填写 Key 和安全密钥。配额、费用、开通要求以高德官方为准。
  3. 2.0.1 没有测试版的“应用并重新加载地图”按钮。填好后，如果只有路线或 Logo 而没有道路建筑，完全退出并重新打开 TTRS，让完整凭据重新加载。
  4. 内置操场路线可点击 恢复默认四点，保持闭合循环及椭圆跑道选项。
  5. 自定义路线先清空默认四点，再搜索自己的地点、按顺序点地图加点。搜索只移动地图，不会自动替换旧点。
  6. 按需要调整目标距离、配速和采样间距；可保存命名路线，日常直接选择。

椭圆跑道需要闭合路线且恰好 4 点；普通开放路线不会循环，长度必须达到发送目标。地图显示与内部 WGS-84 坐标由程序转换，不需手动换算。

高德参考：申请 Web JS API Key、安全密钥说明。请勿公开个人密钥或填好密钥的用户配置目录。

05 / 日常使用

  1. 启动雷电，等待桌面；再启动 TTRS，确认选的是雷电模式、正确的目录与实例。
  2. 选择保存的路线并核对参数，点击预先定位，在目标应用内核对位置。
  3. 在目标应用中开始测试，再点 TTRS 的开始模拟。
  4. 需要中断时使用暂停、继续或停止。TTRS 只控制定位发送，目标应用的计时与保存需要自行操作。
  5. 完成后在目标应用中暂停、结束并处理结果。避免测试中电脑休眠或模拟器意外关闭。
不要套用 2.1.1 的停止界面行为：2.0.1 手动停止后可能保留最后进度；这份正式版保留原程序，没有加入测试版的进度清空和地图重载修复。停止是否生效以不再继续发送定位、状态提示和目标应用实际表现为准。

若只是想下次更容易打开，可分别为雷电和 TTRS.exe 创建桌面快捷方式；不要把 TTRS.exe 从运行目录单独搬到桌面。

06 / 常见问题

提示找不到雷电控制台工具

检查填写的是实际安装目录，不是桌面快捷方式。目录内应有该版本的 ldconsole.exe 或 dnconsole.exe。自定义安装到其他盘时应同步修改程序路径。

提示连续定位失败或 locate 命令失败

先确认对应实例已进入安卓桌面，目录和实例编号正确。完全关闭 TTRS 后重新启动对应实例再试。不同雷电版本的控制台返回和定位行为可能有差异，反馈时提供雷电版本、控制台文件名与报错文字；不要无限重复开始任务。

装了 APK，但没有步数

先确认装的是指定 v2 文件且哈希一致。目标应用需要实际取得定位和距离变化；静止不动不代表兼容 APK 一定生成步数。程序面板的估算步数也不能代替目标应用最终保存的结果。

目标应用提示检测到模拟器、作弊或停止计时

停止本次测试并按目标应用规则处理。本次把版本设为正式版，不代表此前的环境识别问题已被修复；没有新增规避检测逻辑。

高德底图空白

检查同一条 Web 端（JS API）Key 和安全码是否配对，完整退出并重开 TTRS，同时检查网络与高德域名规则。本版没有 2.1.1 的专用重载按钮。

位置不对或一直停在原地

检查选中了正确实例，目标应用的定位权限正常。不要同时播放雷电自己的另一条模拟路线；先预先定位并在目标应用确认，再开始发送。

想使用 Android Studio AVD

2.0.1 仍保留 AVD 模式；需要仅保留 AVD 并测试地图重载、停止清空等改动的用户可使用 2.1.1 测试版。两版放在不同文件夹，避免同时运行。两版可能沿用同一 Windows 用户的已有配置，切换后重新核对模式、目录与路线。

更新、反馈与数据

更新前退出旧程序，完整解压到新目录，不要删除个人配置目录。反馈提供 TTRS、雷电版本、实例编号和报错文字，遮盖账号、地图密钥和其他隐私。本版没有界面化路线导入导出功能。
