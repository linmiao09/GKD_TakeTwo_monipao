# 小猫快跑

Windows 桌面路线模拟工具，支持雷电模拟器和 Android Studio 原生 AVD。

**[下载小猫快跑 2.0.2 正式版（Windows 64 位安装向导）](https://github.com/linmiao09/GKD_TakeTwo_monipao/releases/download/v2.0.2/XiaoMaoKuaiPao-2.0.2-Windows-x64-Setup.exe)** · [查看发布说明](https://github.com/linmiao09/GKD_TakeTwo_monipao/releases/tag/v2.0.2) · [SHA-256 校验文件](https://github.com/linmiao09/GKD_TakeTwo_monipao/releases/download/v2.0.2/SHA256SUMS.txt)

**更名说明：TTRS（TakeTwo Route Simulator）现已更名为「小猫快跑」。** 旧教程中的 TTRS 指的是这款 Windows 桌面工具，不是安卓应用。已发布的旧包没有改名，解压后看到 `TTRS.exe` 是正常的。

本仓库发布可运行软件、使用教程和更新说明，不公开桌面应用的源码工程。

## 2.0.2：安装和首次打开

1. 下载上方的 **`XiaoMaoKuaiPao-2.0.2-Windows-x64-Setup.exe`**，不需要解压或安装 Node.js、npm。安装包尚未进行数字签名；可在下载目录打开 PowerShell，运行 `Get-FileHash .\XiaoMaoKuaiPao-2.0.2-Windows-x64-Setup.exe -Algorithm SHA256`，与上方校验文件中的值核对。
2. 双击安装程序。向导第一页是**使用声明（免责声明）**，请先阅读；同意并勾选后才能继续安装。
3. 从开始菜单打开**小猫快跑**。首次启动时，还要在软件内输入 **`我已阅读并同意承担使用责任`** 才能进入。旧版用户升级后也需重新确认一次，不用清空高德配置或已保存的路线；之后正常启动不再重复询问。
4. 安装包**不含模拟器或 APK**。模拟器需要另行安装，二选一即可：想快速开始，先看[连接雷电](#ldplayer)；已有 Android Studio，则看[连接原生 AVD](#avd)。连好后按[地图设置与路线编辑](#route-editor)配置地图。桌面显示的步数是本地估算，不是真实运动记录。

GitHub 自动提供的 **Source code (zip / tar.gz)** 是这个文档仓库的快照，不是可运行程序。

## 还在使用旧版 TTRS？

以下是旧版 ZIP 的说明；首次下载请选择上方的 **2.0.2 正式版**。

| 历史版本 | 支持的模拟器 |
| --- | --- |
| TTRS 2.0.1（旧正式版） | 雷电、原生 AVD |
| TTRS 2.1.1（测试版，非当前正式版） | 仅原生 AVD，没有雷电选项 |

### 旧版 ZIP 下载后怎么打开？

1. 已有历史发布包的用户，请先把 Windows ZIP **完整解压**到一个独立目录，不要在压缩软件里直接运行。
2. 打开解压目录中的 **`软件\TTRS.exe`**。保留 EXE 旁边所有文件。如果想从桌面启动，请创建快捷方式，不要只把 EXE 移到桌面。
3. 同时保留正式版与测试版时，分别解压到不同目录。切换前先退出另一版，打开后核对设备和路线；不需要删除自己的本机配置。

<a id="ldplayer"></a>

## 连接雷电模拟器

1. 安装雷电模拟器，无需安装 Android Studio。打开小猫快跑（旧版叫 TTRS），在左侧 **选择模拟器** 中选 **雷电**。
2. **雷电安装目录** 填雷电程序所在的文件夹，不是小猫快跑的安装目录，也不是桌面快捷方式。
3. **实例索引** 用来选择要连接的雷电实例。选择对应索引后点击 **启动雷电**，等安卓桌面出现。索引可区分实例，但同时多开尚未测试，请谨慎使用。

<a id="avd"></a>

## 连接原生 AVD

1. 在 Android Studio 的 **Device Manager** 中创建并启动虚拟设备。旧教程使用的组合是 **Pixel 3、Android 9（API 28）、Google APIs x86_64**，这是当时的测试配置。
2. 等安卓桌面出现后打开小猫快跑（旧版叫 TTRS），在 **原生 AVD** 区域刷新设备列表，再选择刚启动的设备。列表为空时，先确认虚拟设备已经开机，再刷新。

<a id="route-editor"></a>

## 配置高德地图、编辑并保存路线

1. 在 **地图与高级设置** 填写自己的高德 **Web 端（JS API）Key** 和同一条 Key 的安全密钥。Android 端 Key 不能代替 Web 端 Key。
2. 如果只能看到路线和高德 Logo，看不到道路或建筑，先核对两项凭据，再完全退出并重新打开桌面程序。旧版 **2.0.1** 也适用；**2.1.1 测试版** 可以直接点 **应用并重新加载地图**。
3. 要画一条新路线，先清空不需要的旧点，搜索地点，再按顺序点击地图加点。**搜索只移动地图，不会添加路线点，也不会替换旧点。**
4. 要让路线首尾相接，勾选 **闭合循环**；要画椭圆跑道，则需闭合且恰好四个点。输入路线名称并点 **保存**，下次从已保存的路线列表选回。

**两个旧版的小区别：** 2.0.1 手动停止后会保留最后一次进度，再次开始时重置；2.1.1 手动停止后会清空实时面板。

## 使用与反馈

仅在自己拥有或获准测试的环境中使用，不要将模拟数据作为真实运动记录提交。第三方软件的权利与许可独立适用。

反馈问题时，请附桌面工具版本、模拟器版本、错误文字和遮挡隐私后的截图；不要公开地图密钥、个人坐标、账号或认证文件。
