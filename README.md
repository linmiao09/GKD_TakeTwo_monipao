## demo二次开发思路
基于此项目的二次开发思路
* 实现步数的功能（雷电模拟器官方文档没有查询到有震动传感器，所以这里换成安卓原生的模拟器或者genymotion的模拟器，需要加ARM的转译）
* 实现自定义路径的功能（调用高德地图或者百度地图，实现点击地图获取坐标，循环路径坐标）
* 实现模拟器人脸识别的功（目前的一个难点：理论上是能实现的，核心就是把主机的摄像头接入模拟器，电脑最好是带Windows hello解锁的）【这个功能适合用于那些需要在固定点人脸识别的乐跑软件，taketwo目前是没有的】
